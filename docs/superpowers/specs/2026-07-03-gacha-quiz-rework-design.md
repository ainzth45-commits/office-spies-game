# Spec: ยกเครื่องกาชา + โจทย์เชาว์ (เคาะโดยเจ้านาย 2026-07-03)

> บริบท: เหรียญเป็นของจริง (ซุปจัดการมือ) — แอปเก็บเฉพาะ ไอเทมในกระเป๋า, เกราะสปาย,
> ตัวคูณค่าโหวต, สถานะโจทย์เชาว์ · เดิม "ร้านลับ" คือช่องทางซื้อไอเทมด้วยเหรียญจริง

## A. เอาร้านลับออก — ไอเทมได้จากกาชาเท่านั้น

- ถอดไอคอน "ร้านลับ" จาก dock หน้าโฮม · ลบ phase `shop` + `ShopFlow` + ราคาไอเทม
  (`itemPrices`) ออกจากตั้งค่า · `buyVoteItem` เหลือ source เดียวคือ gacha
- ข้อความกฎย่อ/สอนเล่นที่อ้างร้านลับ: แก้ขั้นต่ำให้ไม่โกหก (รีไรต์ใหญ่รอบรีฟถัดไป)

## B. กาชาใหม่

### B1. เข้าถึง
- กด dock → เจอตู้ทันที ไม่มีหน้าเลือกผู้เล่น/ยืนยัน · ไม่มีลิมิตต่อวัน (ตัด
  `gachaDailyLimitPerPlayer`, `dailyUsage.gachaSpins`)
- ป้าย "ค่าหมุน N เหรียญ" คงไว้เป็นกติกาจ่ายมือ (config `gachaSpinCost` เดิม)

### B2. ผลกาชา 14 ช่อง (แตกไอเทมรายใบ)
| กลุ่ม | ช่อง | เอฟเฟกต์ |
|---|---|---|
| เหรียญจริง (ข้อความอย่างเดียว) | selfGain, selfLoseAll, allGain, poorGain, allLose | ข้อความอ้าง "คนที่หมุน" — ซุปจัดการเหรียญมือ |
| ค่าโหวต | voteUp, voteDown | เหมือนเดิม (วันละครั้ง → ถอดจากพูลอัตโนมัติ) |
| ไอเทม (แตกใหม่) | itemDouble, itemRemove, itemSwap, itemReduce, itemProtect | หลังเฉลย → กริดผู้เล่น "ใส่ไอเทมให้ใคร?" ซุปกดเลือก → เข้ากระเป๋า (เต็ม 2 ชิ้น → ช่องนั้นถูกถอดจากพูลไม่ได้ — ยังสุ่มได้ ให้คนอื่นรับแทน) |
| โจทย์เชาว์ | grantQuiz | เข้าหน้าโจทย์ทันที ไม่ระบุชื่อ (คนหมุนตอบ) |
| เกราะ | spyShield | เข้า slot สปายอัตโนมัติ · ออกแล้วถอดจากพูลจนจบเกม (เดิม) |

- น้ำหนัก % ราย 14 ช่องในตั้งค่า (บังคับรวม 100 เหมือนเดิม) — **migrate config เก่า**:
  `grantItem` เดิมหารเท่าลง 5 ช่องไอเทม · key อื่น map ตรงชื่อ
- state ใหม่ `pendingGachaGrant: { itemType } | null` — ผลไอเทมค้างรอซุปกดเลือกคนรับ
  (refresh กลางคันต้องกลับมาหน้าเลือกคนรับได้)

### B3. โชว์/ลุ้น
- ตู้ใหญ่เป็นพระเอกกลางจอ (สเกล dvh — ทุก state ต้องจบจอเดียว iPad)
- หมุนนานขึ้น มีจังหวะหน่วงก่อนเฉลย: reel เร็ว → ช้าลง → ค้าง → เฉลย + สั่นแรงขึ้น
  ช่วงท้าย + เสียงรัวถี่ขึ้น (Web Audio เดิม)
- ปุ่ม "📦 ในตู้มีอะไร" → modal กริดของทั้ง 14 ช่อง: รูป (ไอเทมใช้การ์ด item-*.webp,
  ที่เหลือใช้ gacha-result-*.webp) + คำอธิบายสั้น + **% สด** จาก
  `availableGachaWeights` (ช่องที่หลุดพูล เช่น เกราะออกแล้ว แสดงเป็น "หมด/ล็อก")

## C. โจทย์เชาว์ใหม่

### C1. คลังโจทย์ 200 ข้อ (คัดคุณภาพ)
- ทุกข้อเพิ่ม field `difficulty: "easy" | "medium" | "hard"` — โชว์ป้ายบนหน้าโจทย์
- รีวิวของเดิม 100 ข้อ: ข้อกำกวม/เฉลยผิด/ง่ายเกิน → ตัดแล้วเขียนแทน · เขียนเพิ่มจนครบ
  200 คละ 7 หมวดเดิม คละความยาก
- สุ่มล้วนจากข้อที่ยังไม่ใช้ (ไม่เลือกหมวด/ระดับ)

### C2. ประวัติกันซ้ำข้ามรอบเกม
- ย้าย used-ids จาก GameState → **localStorage key แยก** (`office-spies/quiz-used-v1`)
  → เริ่มเกมใหม่/รีเซตเกมไม่ล้าง · ปุ่ม "รีเซตคลังโจทย์" ในตั้งค่า + ตัวเลข ใช้แล้ว X /
  เหลือ Y · คลังหมด → แจ้งชัดตอนกาชาออก grantQuiz (ไม่วนซ้ำเงียบๆ: ข้อความบอก
  "โจทย์หมดคลัง กดรีเซตในตั้งค่า" และไม่เข้า quiz)

### C3. กลไกเวลา (ทุกตัวปรับได้ในตั้งค่า)
- นาฬิกานับเดินหน้า + แถบรางวัลสด "ตอบถูกตอนนี้ได้ X เหรียญ"
- ตอบถูก: `quizCorrectReward` (10) − 1 ทุก `quizRewardDecaySec` (10 วิ) → ต่ำสุด
  `quizRewardMin` (1)
- ตอบผิด ≤ `quizPenaltyTierSec` (60 วิ): ทุกคนเสีย `quizWrongPenaltyPerPlayer` (3) ·
  เกิน: เสีย `quizWrongPenaltyLate` (6) — จบแค่ขั้น 2
- UI เปลี่ยนสี/สัญญาณเมื่อเข้าโซนโทษแรง (เกิน tier)

### C4. หน้าเฉลยผล
- โชว์ ✅/❌ + เฉลยข้อถูก + ผลเหรียญ ("ได้ 7 เหรียญ · ใช้เวลา 32 วิ" / "ทุกคนเสีย 6")
- ไม่เด้งกลับโฮมอัตโนมัติ — ปุ่มกลับ Home กดเอง

## D. ปุ่ม Home ทุกหน้า
- ชิป 🏠 มุมซ้ายบน ตำแหน่งเดียวกันทุกหน้า (render กลางที่ AppRouter เมื่อ phase ≠ home)
- กดกลางหมุนกาชาได้ (GachaFlow เคลียร์ timer ตอน unmount อยู่แล้ว) · กลาง quiz ได้
  (pendingQuiz คงอยู่ กลับเข้ามาเล่นต่อ — ตัวจับเวลาเริ่มจาก startedAt ที่บันทึกใน state
  ไม่ใช่ตอน mount กัน exploit หนีเวลา)

## E. ขอบเขต/ไม่ทำ
- ไม่แตะ flow โหวต/บทบาท/วัน · ไม่รีไรต์สคริปต์สอนเล่น (รอบรีฟถัดไป) · แก้ข้อความที่
  อ้างร้านลับแบบขั้นต่ำเท่านั้น

## F. การทดสอบ
- unit: migrate weights เก่า→ใหม่ · availableGachaWeights ตัดช่องล็อก+เกลี่ย % ·
  applyGachaOutcome ราย outcome (ไม่มี playerId, pendingGachaGrant, กระเป๋าเต็ม) ·
  quiz reward decay/penalty tier ตามเวลา (inject เวลา ไม่ใช้นาฬิกาจริง) · used-ids
  ข้ามรีเซต + reset action
- browser verify จริงบน dev: หมุน→เฉลย→เลือกคนรับ→ของเข้ากระเป๋า · modal ในตู้ ·
  quiz จับเวลา+เฉลย · ปุ่ม Home ทุกหน้า · ทุกหน้าจบจอเดียว iPad (1180×820 และเตี้ยกว่า)
