# 🕵️ เกมที่ 1 — "สายลับในออฟฟิศ" (Office Spies)

เกมกระตุ้นยอดขายแนว **สืบสวนซ่อนบทบาท (social deduction)** สำหรับทีม CRM
เล่นต่อเนื่อง ~1 สัปดาห์ ใช้ "ยอดขาย → เหรียญจริง" เป็นพลังในการเล่นเกมการเมือง โหวต หมุนกาชา และปั่นเกม

> **สถานะ: ✅ เสร็จสมบูรณ์ ใช้งานจริงได้ (เจ้านายเคาะ 2026-07-16)**
> 🎮 เล่นได้ที่: **https://ainzth45-commits.github.io/office-spies-game/**
> รันบน **iPad Air 5 แนวนอน** เครื่องเดียว (แอดมิน/ซุปคุมเครื่อง + ผู้เล่นผลัดกันเดินมาทำรายการ)

## ⚡ แก่นเกมใน 30 วินาที

- ทีมมีสายลับแฝง **2 คน (A & B)** สุ่มลับตอนเริ่มเกม — สปายรู้รหัสคู่ของกันเอง
- ขายของ → รับ **เหรียญจริง** จากซุปตามโปรแต่ละวัน (แอปไม่นับเหรียญรายคน — เหรียญเป็นของจริง ซุปกำกับ)
- เหรียญใช้: **เปิดโหวตจับสปาย** (ทั้งทีมรวมกันจ่าย) · **หมุนกาชา** (ทางเดียวที่ได้ไอเทม) · **ซื้อเบาะแสหลังโหวต**
- **ทีมชนะ** = จับสายลับครบ 2 คนก่อนจบวันที่ 6 · **สปายชนะ** = รอดถึงจบโหวตวันสุดท้าย
- ตัวเลือกเสริม: **คนบ้า (Jester)** — สุ่ม 1 คน ชนะคนเดียวถ้าโดนโหวตออก (เปิด/ปิดในตั้งค่า)
- **ไม่มีใครถูกเตะออกจากเกม** — โดนจับ = เปิดโปง แต่ทุกคนยังขายยังเล่นถึงวันสุดท้าย

## 🎮 วิธีเล่น (flow ต่อวัน)

1. **วันแรก**: แอดมินเข้า ⚙️ ตั้งค่า → 👥 ผู้เล่น ลงทะเบียนทีม (ต้อง ≥ 3 คน) → กด "บทบาท" → ตั้งคนมา/ลา → ผู้เล่นเดินมากดดูบทบาทตัวเองทีละคน (กดค้างถึงเห็น มีม่านกั้นสายตา)
2. **ระหว่างวัน**: ขายของรับเหรียญ · หมุนกาชา (เลือกคนหมุนก่อน ไอเทมเข้ากระเป๋าคนนั้นตรง · สปายหมุนของป่วนออกบ่อยขึ้น) · ตอบโจทย์เชาว์จากกาชา (timer รางวัลลดตามเวลา)
3. **เปิดโหวต** (วันละ 1 ครั้ง · ค่าเปิด = จำนวนคนมา × ค่าต่อหัว × ตัวคูณ): ผู้เล่นเดินมาลงคะแนนลับทีละคน ใช้ไอเทมโหวตได้ (โหวต 2 เสียง/ลบเสียง/สลับผล/ลดเกณฑ์/กันลดเกณฑ์) → นับถอยหลังเปิดผล
   - จับถูกสปาย → ได้สิทธิ์ชี้ตัวสปายคนที่ 2 ทันที (ชี้ถูก = ทีมชนะจบเกม)
   - จับผิดคนบริสุทธิ์ → คืนเหรียญ 1/4 (ทีมตัดสินเองว่าใครไม่ได้) · **ห้ามเผยชื่อคนที่โดน**
   - หลังผลโหวตมีข่าวกรองฟรี (จำนวนสปายในกองคนถูกโหวต เมื่อคนถูกโหวต ≥ เกณฑ์) + ซื้อเบาะแสเพิ่มได้ 1 ครั้ง/รอบ (กอง < 3 คน = เสียฟรี — กับดักโดยเจตนา)
4. **ข้ามวันไม่โหวต** → ค่าเปิดโหวตวันถัดไปแพง ×1.5 สะสม
5. **วันที่ 6 (วันสุดท้าย)**: โหวตครั้งสุดท้าย ไม่สำเร็จ = สปายชนะอัตโนมัติ → ฉากจบเฉลยตัวสปาย

โหมดเสริม: **ฝึกเชาว์** (ซ้อมโจทย์ 200 ข้อ ไม่กระทบเกม) · **ดูภาพ** (topic mode — สปายเห็นรูปต่างจากคนอื่น เดินดูทีละคนแล้วคุยกัน) · **สอนเล่น** 19 ฉาก

## 💻 เทคนิค

- **โค้ด**: `app/` — React + TypeScript + Vite · เทส Vitest (`npx vitest run --pool=forks`) + Playwright
- **Deploy**: push `main` → GitHub Actions → GitHub Pages อัตโนมัติ (`.github/workflows/deploy.yml`) · เช็คของจริง: เทียบ hash `index-*.js` บนเว็บกับ `app/dist/assets/`
- **รัน dev**: `cd app && npm run dev` → localhost:5173 · เทสหน้าจอกับ dist: `ln -sfn dist office-spies-game` + `python3 -m http.server`
- ⚠️ **repo เป็น public** — ห้าม commit ชื่อจริง/รูปพนักงานลง source/เทส (รายชื่อจริงอยู่ใน IndexedDB ของ iPad เท่านั้น)
